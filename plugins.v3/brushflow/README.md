# 站点刷流

站点刷流 V5 使用 Vue 模块联邦提供任务工作台，每项任务独立绑定站点和下载器。自定义版本 6.2.1，作者 seiun,jxxghp,InfinityPacer,Seed680。

## 全局删除策略

工作台右上角新增独立的“全局删除策略”页面，统一配置容量和删种条件。任务详情及种子列表显示实际生效的全局策略。任务编辑页显示全部清理条件，每项留空继承全局，填写后覆盖对应全局值。促销过期支持继承、启用、关闭三态。任务未活动时间以分钟填写，全局以小时填写。

当前建议配置如下。

- 新增下载容量上限 600 GB。
- 达到 550 GB 启动清理，降至 450 GB 或以下停止。
- 累计做种达到 168 小时，或连续未活动达到 48 小时，满足任一项即可参与容量清理。
- 各任务开启全局托管，保留 MOVIEPILOT 和 H&R 排除标签。

累计时间取 qBittorrent 的 seeding_time，不使用完成后的自然时间。连续未活动按 last_activity 判断，起点不得早于完成时间，当前上传或下载速度必须为零。缺失、为零或处于未来的活动时间不用于判定未活动，但不影响有效的累计做种条件独立判断。异常状态不删除。未完成下载仅使用下载超时或促销过期条件，默认不启用。

**这是或关系。未满 7 天的种子也可以因连续 48 小时未活动而取得清理资格。** 达到条件不会立即删除，仍须容量触发。任务的 min_seed_hours 保留兼容字段名，界面改称“累计做种目标”，它覆盖全局累计目标（允许调低），只作用于累计做种分支，不会阻止未活动分支。相同 Hash 归属多个任务时，每个任务的有效策略都必须至少命中一个条件。

共用文件按同一下载器的规范化文件路径建立关联组，包括未标记刷流的辅种和部分文件交叠。关联组每个种子均需满足任一条件，不同种子可以满足不同条件。H&R、保护标签和不参与托管的任务仍然保护整组。没有合格种子时停止清理，新增容量上限继续生效。

删除前逐组重新读取文件和任务数据，删除后确认任务已移除，再更新刷流统计。guard_last_run 保存阈值、跳过原因、每个种子实际命中的条件和删除确认状态。

当前只支持所有启用刷流任务共用一个 qBittorrent 下载器，不跨下载器或不同路径别名识别共用文件。不能拦截外部工具删除，也不能与外部添加任务实现完全原子互斥。Tracker 的 H&R 规则不由下载器累计时间代替。

关闭全局托管但保留累计或未活动策略时，停止自动删除。仅在全局及各任务的自定义策略全部清空后恢复上游普通删除行为。旧版未配置自定义策略的动态清理保持兼容，完整源码保留原实现。

## 完整清理条件和显示

全局页面保留累计做种时间、连续未活动时间、分享率、上传量、下载超时、平均上传速度、H&R 做种时间、促销过期及保护标签。空值或关闭表示不启用，不会因为未使用而删除选项。当前配置仍只启用累计 168 小时或未活动 48 小时。

普通已完成种子按累计时间、未活动、分享率、上传量或平均上传速度判断。平均速度沿用原插件口径，累计上传量除以添加后的经过时间，做种至少 30 分钟后才判断。未完成种子仅按下载超时或已知促销截止时间判断。H&R 单独使用 H&R 累计时间或分享率，普通条件不能绕过 H&R。任务排除标签留空继承全局，填写后覆盖，且只影响本任务，未归属任务的关联辅种使用全局策略。任意关联所有者的保护规则均能阻止整组删除。全局默认包含 MOVIEPILOT 和 H&R。

状态栏仅显示做种中、下载中和已删除，不显示策略或删除原因。桌面策略显示简短摘要，鼠标悬停或键盘聚焦显示完整说明。手机布局直接显示完整策略。

## 升级兼容

- V5 依赖 MoviePilot `v2.14.6+` 提供的 Vue 联邦宿主能力，旧版宿主会在安装和更新前拒绝该版本。
- 首次加载 V5 时，旧版 `brushsites` 会按站点拆分为独立任务。
- 从 V4 直接升级时，原有运行限额和全局动态删种会迁移到新的全局设置，已升级到 V5 的用户可在全局设置中重新设置合计限额。
- 旧版站点覆盖 JSON 会合并到对应任务中。
- 原有种子、归档和未托管数据会按站点迁移到任务命名空间。
- 已有的全局 `刷流` 标签继续识别，V5 新增任务唯一标签，避免多个任务互相接管。
- V5.0.2 会在插件启动、任务检查和任务删除后清理 qBittorrent 中不再被任何种子使用的 `刷流-*` 标签，仍绑定种子的标签不会被强制移除。
- V5.1.0 新增站点账号分享率目标控制，并限制运行诊断长列表在模块内部滚动。
- V5.1.1 修复 YemaPT 间接下载链接只返回 token、导致刷流任务无法获取种子 Hash 的问题。
- V5.1.2 会在最近的免费促销截止时间即时检查未完成下载，同时保留周期检查兜底，并修正跨时区到期判断。
- V5.2.0 恢复 V4 的全局动态删种，并适配 V5 的多任务、多下载器和任务级托管开关。
- V5.2.1 修复同一下载器共享种子的跨任务保护，并按任务记录实际删除原因。
- V5.2.2 将详情弹窗的滚动限制在右侧工作区，固定顶部标题栏和左侧任务栏，并移除重复失效的配置切换按钮。
- V5.2.3 兼容 qBittorrent 5.2.3，修复动态删种后的未使用标签清理报缺少 `hashes` 参数。

## 前端入口

插件构建产物暴露以下联邦组件：

| 组件 | 用途 |
| --- | --- |
| `AppPage` | 主界面侧栏中的完整刷流工作台 |
| `Page` | 插件详情弹窗 |
| `Config` | 插件配置弹窗 |
| `Dashboard` | 仪表板任务概览 |

侧栏入口由插件的 `get_sidebar_nav()` 注册，可在工作台全局设置中关闭。

## 插件 API

所有接口均使用宿主 Bearer 认证，基础路径为 `/api/v1/plugin/BrushFlow`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/status` | 获取全局状态、任务摘要与可选站点下载器 |
| `POST` | `/settings` | 更新插件与侧栏入口开关 |
| `POST` | `/tasks` | 创建任务 |
| `GET` / `PUT` / `DELETE` | `/tasks/{task_id}` | 查询、更新或删除任务 |
| `POST` | `/tasks/{task_id}/state` | 启用或暂停任务 |
| `POST` | `/tasks/{task_id}/run` | 立即执行刷流刷新 |
| `POST` | `/tasks/{task_id}/check` | 立即执行种子检查 |
| `POST` | `/tasks/{task_id}/clear` | 清除当前任务的独立数据 |

## 构建

在本目录安装依赖后执行 `yarn build`，产物生成到 `dist/assets`，由插件后端的 Vue 渲染模式加载。

5.2.8 桌面摘要按生效条件生成，例如“全局托管 · 7天或闲置2天”。悬停和手机显示完整容量、条件与保护规则。
