# 自动订阅 1.1.2

作者：seiun

仓库：https://github.com/zhangyxXyz/MoviePilot-Plugins

MoviePilot V3 插件，侧栏入口为「订阅 → 自动订阅」。统一管理热门媒体、豆瓣榜单、演员作品、将映关注和豆瓣想看。

## 任务与顺序

每张卡片是一套独立的规则、执行周期和新增上限。拖动或上下移动可以调整顺序。任务有固定 ID，编辑时原位保存，新建追加末尾，历史按任务 ID 关联。排序不决定任务的执行优先级。

热门媒体的门槛是 MoviePilot 订阅人次，需要启用系统订阅数据共享。豆瓣任务使用豆瓣评分，TMDB 用于媒体识别，豆瓣评分不可用时等待重试。演员作品支持姓名或 TMDB 人物 ID，姓名有歧义时不自动选人。将映关注支持片名和年份，默认识别后订阅，可改为临近上映才订阅。

每次新增上限只统计成功创建的订阅。重复、失败、媒体库已存在不占额度。五种来源统一检查已有订阅与媒体库，媒体标识包括来源、类型、ID 和季数。失败和限额延后的条目持久化，下轮可重试。已订阅作品的下载、洗版和完成后的订阅管理交由 MoviePilot 处理。

豆瓣想看每个账号一个任务，填写个人主页里的账号 ID，默认每 30 分钟读取最近 7 天的想看动态，不以评分和年份拦截主动选择的作品。只同步想看，忽略看过、在看。RSS 仅提供近期公开动态，首次同步不能保证获取全部历史想看。取消豆瓣想看不会删除已经创建的订阅。

## 订阅历史

按来源、任务、媒体类型查看海报历史，待处理与跳过记录单独展示。隐藏历史只影响展示，不清理去重账本，不删除真实订阅。未成功条目可以手动加入下轮重试。

## 验证和构建

前端运行 `npm ci`、`npm run build` 和 `npm test`。后端测试为 `tests/v3/autosubscribe/test_core.py`，需要 MoviePilot Python 环境。插件使用 Vue 联邦模块，管理接口要求宿主管理权限。

实现参考了 MoviePilot 以及 jxxghp、thsrite、boeto 维护的对应插件行为，新界面和统一执行器由本仓库实现。原项目许可证见仓库 LICENSE。

订阅历史会关联 MoviePilot 当前订阅及完成历史，每分钟刷新状态。已创建的统一显示“已创建订阅”，宿主完成历史或扫描确认媒体库完整存在的条目进入“已完成”。同一作品按媒体类型和季度分别匹配，仍在进行的订阅（包括洗版）优先显示为已创建。删除订阅不会被当作完成。此分类不修改宿主订阅或原始扫描记录。
