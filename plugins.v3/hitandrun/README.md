# H&R助手

作者：seiun, InfinityPacer。基于原 H&R助手重组，版本仍为 2.0.0。
仓库：https://github.com/zhangyxXyz/MoviePilot-Plugins

仅识别和维护保护标签，不暂停或删除种子。下载事件与每下载器的 Cron 扫描共用持久化记录。明确 H&R、待确认两种保护标签可改名；扫描先加新标签再移除自有旧标签。其他标签保持不变。

每个关联站点分别满足 `下载完成 AND (累计做种小时 OR 分享指标)` 后解除；CARPT 可用上传量/完整体积。未知站点使用下载器任务的兜底时长。未知 H&R 同样按时长/指标处理，无额外周期性站点请求。判断是本地估算，不声称站点账户确认达标。

额外标签任意命中即按 H&R。任务开启“达标后同时移除额外标签”时，解除保护的同时移除这些来源标签；默认关闭。已达标记录不因辅种标签重复进入保护；Hash 被移除后重加、添加时间变化时重新判断。历史普通任务不自动纳管，显式配置的额外标签可以纳管历史任务。

刷流保护本助手的标签名称。种子清理按各任务明确配置的保护标签判断：选用助手标签的任务自动跟随改名，未选用的任务不隐式保护 H&R。两者均不调用 H&R 判断接口。人工保留标签和共享文件保护仍生效。每个下载器任务开关同时控制下载事件识别和扫描，无额外总开关。停用任务后已有标签继续保护，新下载不再自动识别。

现场迁移：原种子清理 `hr_records/hr_events` 备份后一次性迁移到本插件，包含标签所有权及历史豁免；旧插件事件和周期写入已移除。迁移后保留原文件作为回滚备份。

工作台：左侧选择下载器任务或站点规则，右侧查看策略、扫描记录和种子状态。手动检查只处理当前下载器任务。最近 100 轮扫描按任务记录检查/变更/失败数及已确认的标签增删，单任务每轮最多保存 200 条变更明细。

下载器任务可设置生效站点。默认“全部站点”包含后续新增站点，未知站点使用兜底时长；关闭后仅处理所选站点，空选不处理任何种子。事件识别与扫描使用同一范围，范围外已有标签保留。任一关联站点命中即可纳管，解除仍须所有关联站点分别达标。
